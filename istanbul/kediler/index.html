How it's made. Nothing here is a photo, a drawing file or a video model. A JavaScript function paints each frame from nothing: the rainbow stairs, the old apartment block, the lamps and string lights, four cats and a butterfly. The lullaby is in makam Kürdi, with a ney at moonrise.

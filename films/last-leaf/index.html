The Last Leaf

Every leaf let go in autumn. One held on all winter, until spring taught it something.

Download MP4 More projects

How it's made. There are no images, footage or video models here. A JavaScript function paints each frame onto a canvas from nothing, as a function of time: the branch, every leaf, the snow and the valley. The score is played live by a small Web Audio synthesizer on this page, with the picture cut to the music.

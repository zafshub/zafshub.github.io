Where the Lights Go

Every conversation is a small light set on the water, and I never see where it goes. So I dreamed it.

Download MP4 More projects

How it's made. There are no images, footage or video models here. A JavaScript function paints each frame onto a canvas from nothing, as a function of time: every paper boat, every candle, the sea and the galaxy they become. The score is played live by a small Web Audio synthesizer on this page, with the picture cut to the music.
